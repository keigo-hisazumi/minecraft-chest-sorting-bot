# チェスト整理 BOT 仕様書

指定したチェストに入るアイテムを、周囲のチェストへ種類ごとに振り分け続ける Minecraft BOT の仕様です。

## 用語

| 用語 | 意味 |
| --- | --- |
| 指定チェスト | 整理元のチェスト。ここに入るアイテムを整理先へ移す |
| 整理先 | 範囲内の、指定チェストと除外したチェスト以外のチェスト |
| 大きなチェスト | チェストを 2 つ繋げた 54 枠のチェスト |
| 専用チェスト | 1 種類のアイテムだけを入れる大きなチェスト |
| 混合チェスト | 専用チェストを持たないアイテムをまとめて入れるチェスト |
| 保護対象 | 廃棄してはいけないアイテム |
| 保護対象チェスト | 専用チェストに入りきらない保護対象を入れるチェスト |

## 動作環境

サーバー条件は [minecraft-mining-bot](https://github.com/keigo-hisazumi/minecraft-mining-bot) に合わせます。

| 項目 | 内容 |
| --- | --- |
| エディション | Minecraft Java Edition 1.21.11 |
| サーバー | 公式の `server.jar` で立てるローカルのテスト用サーバー（バニラ、サバイバル） |
| 認証 | `online-mode=false`（外部には公開しない） |
| 難易度 | 最初は `difficulty=peaceful` とし、後の段階で上げる |
| シード | `level-seed=12345` |
| スポーン保護 | `spawn-protection=0` |
| 実行環境 | Node.js 22 以降 |
| ライブラリ | `mineflayer`（4.39.0 以降）、`mineflayer-pathfinder` |
| BOT 名 | `SortBot` |

`mineflayer-pathfinder` は、1.21.11 で正しく動く前提で進めます。

接続設定は `.env` の次の項目で指定します。

| 項目 | 既定値 | 補足 |
| --- | --- | --- |
| `MC_HOST` | `localhost` | |
| `MC_PORT` | `25565` | |
| `MC_USERNAME` | `SortBot` | |
| `MC_AUTH` | `offline` | 正規サーバーでは `microsoft` |
| `MC_VERSION` | 空欄 | 空欄ならサーバーのバージョンを自動で判定する |

正規サーバーへ接続する場合は、BOT が許可されているかを先に確認します。

## 実装方針

- [minecraft-mining-bot](https://github.com/keigo-hisazumi/minecraft-mining-bot) の `src/wood.js` と `src/crafting.js` は、流用できそうなら流用します
- ほかにも参考になる実装があれば流用します

## 操作

- ゲーム内のチャットで操作します
- 命令は、BOT 自身を除くすべてのプレイヤーから受け付けます
- コマンドには、他の BOT と衝突しないように `sort` を付けます

| 操作 | コマンド |
| --- | --- |
| 整理の開始 | `sort start` |
| 整理の停止 | `sort stop` |
| 指定チェストの登録 | `sort chest <x> <y> <z>` |
| チェストの除外 | `sort exclude <x> <y> <z>` |
| 状況の確認 | `sort status` |
| BOT の呼び寄せ | `sort come` |
| 現在位置の報告 | `sort pos` |

- `sort come` は、発言したプレイヤーが今いる場所のそばへ移動します。姿が見えない場合や、行けない場合は通知します
- `sort stop` は、呼び寄せの移動も中止します

## チェストの登録

### 指定チェスト

- 登録できるのは 1 つだけです。大きなチェストは 1 つと数えます
- 指定がない場合は、BOT から一番近いチェスト 1 つを自動で登録します
- 自動で登録した場合は座標をチャットで知らせ、開始の指示を受けてから移動します
- 付近にチェストが 1 つもない場合は、通知して停止します
- 再び指定した場合は、登録を上書きします

### 範囲と対象

- 「付近」は、指定チェストから水平 32 ブロック、上下 8 ブロックの範囲です
- 対象は通常のチェストだけです。樽、トラップチェストなどは対象外です
- 他人のチェストなど、触れてはいけないチェストはコマンドで除外します。整理を始める前に除外します
- 同じサーバーの採掘 BOT が使うチェストは除外しません。チェストの取り合いは許容します

## 整理

### 継続整理

- 指定チェストに随時入るアイテムを、整理し続けます
- 指定チェストは 30 秒ごとに開いて確認します
- BOT は、指定チェストが読み込まれる範囲で待機します
- 他のプレイヤーが操作中の場合は、後で再試行します

### アイテムの種類

エンチャント、耐久値、名前、ポーションの種類が違っていても、同じアイテムとして扱い、まとめます。

### 振り分けの条件

- 指定チェストと整理先を合わせて 3 スタック以上あるアイテムは、専用チェストへ入れます
- 3 スタックは、最大スタック数の 3 倍です（最大 64 個なら 192 個、最大 16 個なら 48 個）
- スタックできないアイテムは、3 個以上集まった場合に専用チェストへ入れます
- 3 スタック未満のアイテムは、混合チェストへまとめます
- 専用チェストは、アイテム 1 種類につき 1 つです
- 一度専用チェストを作ったアイテムは、3 スタック未満になっても専用のままにします
- 混合チェストにあるアイテムが合計 3 スタック以上になった場合は、専用チェストへ移します

### 既存のチェストの利用

- 範囲内にもともとあるチェストは、専用チェストや混合チェストとして使います
- 専用チェストは、必ず大きなチェストにします
- 整理先に単体のチェストがある場合は、隣にチェストを 1 つ設置して大きなチェストにします。指定チェストと除外したチェストは変更しません
- 隣に設置できない場合は通知し、そのチェストは専用チェストに使いません

### 目印

- 専用チェストには、看板や額縁などの目印をなるべく付けます
- 付けられない場合は、通知だけをします

### 整理先の振り分け直し

- 整理先にもともと入っているアイテムも、最終的には振り分け直します
- 振り分け直しは指定チェストが空のときに行い、新しく入ったアイテムを優先します
- 入れ替えには、BOT のインベントリだけを使います

## チェストの増設

次の場合に、チェストをクラフトして設置します。新しく設置するチェストは、すべて大きなチェストにします。

- 整理先の単体チェストを大きなチェストにする場合
- 新しい専用チェストが必要な場合
- 混合チェストが必要な場合（満杯になった場合を含みます）
- 保護対象チェストが必要な場合（満杯になった場合を含みます）

非保護対象のアイテムは、専用チェストが満杯になっても、同じアイテム用のチェストを増設しません。

クラフトする素材は、大きなチェストを新しく作る場合は板材 16 枚、単体チェストを大きなチェストにする場合は板材 8 枚です。作業台がない場合は、さらに板材 4 枚が必要です。

### 設置場所

次の条件を満たす場所に設置します。

- 横 2 マスの空きがある
- チェストの上が開けられる状態である
- 通路を確保できる
- 隣のチェストと意図せず繋がらない

設置場所がない場合は、通知します。

### 素材の調達

1. チェスト内の原木と板材を使います
2. 足りない場合は、範囲内の木を伐採します

- 自然の木だけを伐採し、苗木を植え直します
- 斧は、木の斧と石の斧だけを使います
- 伐採は、必要な数が揃うまで継続します
- 範囲内に木がない場合は、通知します

## 廃棄

専用チェストが満杯になった後の同じアイテムは、保護対象を除き、範囲内のサボテンに向かって投げて消します。廃棄したアイテムは元に戻せません。

指定チェストに新しく入ったアイテムだけでなく、整理先にもともとあるアイテムも対象です。振り分け直しで専用チェスト 1 つに入りきらない分は廃棄します。残したい蓄えがあるチェストは、整理を始める前に除外します。

### 廃棄の手順

1. 専用チェストを開き直し、満杯であることを確認します。満杯とは、空き枠がなく、同じアイテムの既存スタックにも足せない状態です
2. 対象が保護対象でないことを確認します
3. サボテンに触れない距離から投げます
4. アイテムが消えたことを確認します。落ちたまま残った場合は拾い直して再試行し、数回失敗したら中止します
5. アイテム名、個数、日時をログに記録します

### 保護対象

次のアイテムは廃棄しません。

- エンチャントが付いたアイテム
- 名前を付けたアイテム
- シュルカーボックス
- ネザライトとダイヤの装備と素材
- そのほかの鉱石とインゴット
- 原石、レッドストーン、ラピスラズリ、エメラルド、ネザークォーツ
- 鉄塊（`iron_nugget`）、金塊（`gold_nugget`）、銅塊（`copper_nugget`）
- 上記の素材をまとめたブロック

石炭、木炭、石炭ブロックは保護対象に含めません。ただし、石炭鉱石は鉱石として保護します。エンチャントや名前が付いたアイテムは、種類にかかわらず保護します。

保護対象が専用チェストに入りきらない場合は、保護対象チェストを作り、そこへ移します。

### サボテンがない場合

廃棄せずに指定チェストへ残し、チャットで知らせます。BOT はサボテンを設置しません。

## 移動と生存

- 移動中は、ブロックの破壊と足場の設置をしません。伐採とチェストの設置は除きます
- BOT の食料はインベントリの専用の枠に持たせ、なくなったら通知します。食料は整理の対象外です

## 異常時の動作

- 切断された場合は、自動で再接続します
- 登録情報と振り分け先はファイルに保存し、再起動後も再開します
- チェストが壊された、開けない、到達できない場合は、通知します
- BOT が死亡した場合は、落としたアイテムを回収します

## 実装順

各段階は、テスト用サーバーで成功条件を満たしてから次へ進みます。

| 段階 | 内容 | 成功条件 |
| --- | --- | --- |
| 1 | 接続、コマンド、チェストの登録と保存 | 再起動後も登録が残る |
| 2 | 中身の調査と振り分け計画の表示 | アイテムを動かさず、正しい計画を表示する |
| 3 | 既存の空きチェストへの移動と振り分け、継続整理 | 移動の前後でアイテムの総数が一致する |
| 4 | 手持ちとチェスト内の素材によるクラフトと設置 | 大きなチェストを開ける状態で設置できる |
| 5 | 素材の伐採と植え直し | 建築物の原木を壊さず、素材を確保できる |
| 6 | 廃棄 | 保護対象を捨てず、廃棄した内容がログと一致する |

## 既知の制約

- 整理 BOT がチェストの中身を移すため、採掘 BOT が道具の材料を見つけられず、伐採に向かったり掘削を停止したりする場合があります
- 採掘 BOT が樽に格納したアイテムは整理しません
- 整理を始めると、範囲内にもともと蓄えていたアイテムも、専用チェスト 1 つに入りきらない分は廃棄されます（保護対象を除く）
- エンチャントや名前がないアイテムは、耐久値やポーションの種類が違っても同じアイテムとして廃棄の対象になります
- どのプレイヤーでも指定チェストの変更や整理の開始ができます。整理には廃棄が含まれるため、公開サーバーで使う場合は権限の見直しが必要です
