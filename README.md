# minecraft-chest-sorting-bot

指定したチェストのアイテムを、周囲のチェストへ振り分け続ける Minecraft BOT です。

## 主な機能

- Minecraft Java Edition のサーバーに BOT として接続し、切断されたら再接続する
- チャットコマンドで整理元の指定チェストを登録する（指定がなければ一番近いチェストを登録する）
- チャットコマンドで触れてはいけないチェストを除外する
- 登録内容と開始の状態を保存し、再起動後も引き継ぐ
- 周囲のチェストの中身を調べ、アイテムを動かさずに振り分けの計画を表示する
- 指定チェストのアイテムを、専用チェストと混合チェストへ振り分け、整理先の中身も入れ替える
- 整理を開始すると、指定チェストを 30 秒ごとに確認して整理し続ける
- チェスト内の原木と板材からチェストを作り、単体チェストを広げ、足りない大きなチェストを置く
- 専用チェストに入りきらないアイテムを、保護対象を除いてサボテンで廃棄し、記録する
- 材料が足りなければ、範囲内の自然の木を伐採する
- 伐採とクラフトを始めるときにチャットで知らせる
- 指示した場合だけ、伐採した場所に苗木を植え直す
- チャットコマンドで BOT をプレイヤーのそばへ呼び寄せ、現在位置を確認する

## 使い方

1. Minecraft Java Edition 1.21.11 のテスト用サーバーを起動する（サーバーの条件は [仕様書](./docs/spec.md) の「動作環境」を参照する）
2. `.env.example` を `.env` にコピーし、接続先を設定する
3. `npm start` で BOT を起動する
4. クライアントから同じサーバーに入り、BOT が「起動しました: SortBot（使い方は sort help と発言してください）」と発言することを確かめる
5. 指定チェストの近くで、`sort chest <x> <y> <z>` と発言して指定チェストを登録する
6. 動かしてはいけないチェストを `sort exclude <x> <y> <z>` で除外する
7. `sort plan` で振り分けの計画を確認する
8. `sort start` で整理を開始する。範囲内の除外していないチェストは中身が入れ替わり、原木と板材はチェストの材料に使われ、周囲にチェストと作業台が置かれ、材料が足りなければ木が伐採される。サボテンがあれば、専用チェストに入りきらないアイテムは廃棄される（元に戻せない）

## チャットコマンド

命令は、BOT 自身を除くすべてのプレイヤーから受け付けます。

| コマンド | 動作 |
| --- | --- |
| `sort chest <x> <y> <z>` | 指定した座標のチェストを指定チェストとして登録する。登録し直すと上書きする |
| `sort exclude <x> <y> <z>` | 指定した座標のチェストを除外する。指定チェストは除外できない |
| `sort start` | 整理を開始する（下の「整理の動作」を参照）。指定チェストがない場合は一番近いチェストを登録するので、もう一度発言する |
| `sort stop` | 整理、調査、移動を中止する |
| `sort status` | 状態、指定チェスト、除外したチェストを答える |
| `sort plan` | 指定チェストと周囲のチェストを順に開いて中身を調べ、振り分けの計画を表示する（下の「振り分けの計画」を参照） |
| `sort fell <本数>` | BOT の周りの自然の木を、指定した本数（1〜40）だけ切る。切った原木は BOT が持つ。整理中は受け付けないため、先に `sort stop` する |
| `sort replant` | 伐採して記録した場所に苗木を植え直す。整理中は受け付けないため、先に `sort stop` する |
| `sort come` | 発言したプレイヤーが今いる場所のそばへ移動する。移動中はブロックを壊さず、足場も置かない |
| `sort pos` | BOT の現在地の座標を答える |

- 対象は通常のチェストだけです。大きなチェストは、どちらの座標を指定しても 1 つのチェストとして扱います
- BOT の周囲で読み込まれていない座標は登録できません
- 一番近いチェストは、BOT から水平 32 ブロック、上下 8 ブロックの範囲で探します
- 登録内容は、接続先とディメンションごとに `data/state.json` へ保存します（Git の対象外）
- 除外を取り消すコマンドはありません。取り消すときは、BOT を停止して `data/state.json` の `excluded` から該当する座標を削除します
- ワールドを作り直した場合は、`data/state.json` を削除します
- `data/state.json` が壊れている場合、BOT は起動しません

## 振り分けの計画

`sort plan` は、指定チェストから水平 32 ブロック、上下 8 ブロックの範囲にある、除外していないチェストを調べます。アイテムは動かしません。

- チャットでは要約を知らせます。アイテムごとの割り当て先などの詳細は `data/plan.txt` に書き出し、コンソールにも表示します
- 「廃棄予定」は、整理を実行した場合に専用チェストに入りきらず捨てることになる数です。残したいアイテムがあるチェストは、`sort exclude` で除外します
- 開けないチェストや行けないチェストは、理由を知らせて計画から外します
- 調査中は、`sort stop`、`sort status`、`sort pos` 以外のコマンドを受け付けません
- 計画は、足りないチェストを作り、単体チェストを大きなチェストに広げた場合のものです。チェストを置く場所があるかは確認しません

## 整理の動作

`sort start` で開始すると、範囲内を調査して、足りないチェストを作ってから、指定チェストのアイテムから順に移します。指定チェストから移すものがなくなると、整理先どうしの中身を入れ替えます。

- 合計が最大スタック数の 3 倍以上のアイテムは、アイテムごとの専用チェストへ、それ以外は混合チェストへ入れます
- 一度専用チェストを作ったアイテムは、少なくなっても同じチェストへ入れます
- その後は指定チェストを 30 秒ごとに確認し、中身が変わると整理します。開けないチェストがある、材料や置く場所が足りないなどの場合は、約 5 分後にやり直します
- 専用チェストに入りきらないアイテムは、保護対象を除いてサボテンに投げて廃棄します（下の「廃棄」を参照）。保護対象は、保護対象チェストへ移します
- BOT のホットバー（9 枠）は食料などの持ち物に使え、整理しません。斧を持ち、チェストと作業台、指示された苗木を置くときに使うため、**3 枠以上空けてください**。**残りの 27 枠にあるアイテムは、チェストへ移します**
- 整理中に `sort stop` した場合、運んでいる途中のアイテムは BOT が持ったままになり、次の `sort start` で続きを行います
- 切断や再起動のあとは、開始の状態なら整理を再開します。以前の版で保存した開始の状態は引き継ぎません
- 次の確認を待っている間に `sort come` で呼び寄せても、次の確認で指定チェストへ戻ります
- BOT が死亡した場合は、整理を停止して場所を知らせます。落としたアイテムは回収しません

## 廃棄

専用チェストに入りきらないアイテムは、指定チェストから水平 32 ブロック、上下 8 ブロックの範囲にあるサボテンに投げて廃棄します。**廃棄したアイテムは元に戻せません。**

- **もともと蓄えていたアイテムも対象です**。1 種類につき大きなチェスト 1 つを超える分は廃棄します。残したいチェストは、開始する前に `sort exclude` で除外し、`sort plan` の「廃棄予定」を確認します
- エンチャント付き、名前付き、シュルカーボックス、中身のある入れ物、鉱石とインゴットなどは廃棄しません。対象の一覧は [仕様書](./docs/spec.md) の「保護対象」を参照します
- 保護対象でなければ、耐久値やポーションの種類が違っても、同じアイテムとして廃棄します。記入した本や地図なども、保護対象の一覧にないため廃棄の対象です
- 専用チェストを開き直して空きがないことを確かめてから、サボテンから 1 マス空けた場所に立って投げ、消えたことを確かめます
- 拾い直せない場所に残った場合や、3 回続けて確認できない場合は、廃棄をやめて知らせます
- サボテンがない場合や、投げる場所がない場合は、廃棄せずに残して知らせます。BOT はサボテンを置きません
- 廃棄の記録は `data/discard.log` に追記します（Git の対象外）。各行は日時、結果、アイテム名、個数をタブで区切ります。結果が `廃棄` の行が、消えたことを確認できた分です

## チェストの作成と設置

- 整理先の単体チェストは、隣にチェストを置いて大きなチェストにします。指定チェストと除外したチェストは変更しません
- 専用、混合、保護対象のチェストが足りない場合は、大きなチェストを指定チェストの近くに新しく置きます
- 材料は、BOT の持ち物と、除外していないチェストの原木と板材です。板材は種類が混ざっていても使います。名前を付けたものは使いません。足りなければ伐採します（下の「伐採と植え直し」を参照）
- 範囲内に作業台がなければ、作って置き、そのまま残します
- 置く場所は、上と正面が空いていて、ほかのチェストと意図せず繋がらず、ほかのチェストの正面や扉の隣をふさがないマスから選びます。条件を満たす場所がなければ知らせます
- 通れなくなる場所がないかは完全には判定しないため、置かれて困る場所がある場合は、置いたあとの状態を確認してください
- 開けないチェストや行けないチェストがある間は、新しい大きなチェストを作りません。`sort exclude` で除外すると作れるようになります

## 伐採と植え直し

チェストの材料が足りない場合は、指定チェストから水平 32 ブロック、上下 8 ブロックの範囲の木を伐採します。

- 地面から生え、自然の葉があり、隣に人が置いたと考えられるブロックがない幹だけを切ります。詳しい条件は [仕様書](./docs/spec.md) の「伐採する木」を参照します
- **自然に生えた形のままの植林地や街路樹は、区別できないため伐採されます**
- 地上から手が届かない大きな木（根元からの高さ 31・水平の広がり 4 まで）は、根元の原木を切った跡に立ち、持っている原木を足元に積んで登りながら切ります。切り終えたら積んだ原木を上から掘って降りるため、柱は残りません。積む原木がないときは、届く原木だけを切ります
- 斧は木の斧と石の斧だけを使います。持ち物とチェストになければ作り、材料がない間は素手で切ります
- 伐採中は、道をふさぐ自然の葉を壊すことがあります。大きな木を登るとき以外は、足場を置きません
- 木を 1 本切る前と、板材、棒、斧、作業台、チェストをクラフトする前に、チャットで知らせます

`sort fell <本数>` で、整理とは別に、周りの木を指定した本数だけ切ることもできます。

- 木を探す範囲は、指定チェストではなく、BOT の今いる場所から水平 32 ブロック、上下 8 ブロックです
- 切る木の条件、斧の扱い、知らせ方は、整理の中の伐採と同じです。ただし、斧を作るときは範囲内の作業台を使い、作業台を新しくは置きません。チェストの斧や苗木は取り出しません
- 指定した本数に達するか、切れる木がなくなるか、持ち物の空きがなくなったらやめて、結果を知らせます
- 切った場所は記録し、`sort replant` で植え直せます

苗木の植え直しは、`sort replant` と指示した場合だけ行います。

- 伐採した場所は記録し、整理の結果と `sort status` で数を知らせます
- 苗木は、BOT の持ち物と、指定チェストがあれば範囲内の除外していないチェストから使います。伐採中に落ちていた苗木は拾いますが、苗木を集めるために葉を壊すことはしません
- 苗木が足りない場所は記録に残り、次の `sort replant` で植えます
- ダークオークとペールオークは、苗木が 4 本そろわないと育ちません

## 開発

### 必要な環境

- Node.js 22 以降
- Minecraft Java Edition のサーバーとクライアント（動作確認用）

### コマンド

```bash
npm ci          # 依存関係のインストール
npm start       # BOT を起動する
npm test        # テストを実行する
npm run build   # src/ と scripts/ の構文を検査する
```

## ディレクトリ構成

```text
.
├── src/
│   ├── index.js          # BOT のエントリーポイント（接続と再接続）
│   ├── config.js         # 接続設定（環境変数から読み込む）
│   ├── commands.js       # チャットコマンドの解釈
│   ├── controller.js     # コマンドの実行
│   ├── chests.js         # チェストの判定と検索
│   ├── navigation.js     # BOT の移動
│   ├── survey.js         # チェストの中身の調査
│   ├── items.js          # 保護対象の判定
│   ├── plan.js           # 振り分けの計画
│   ├── planreport.js     # 計画と整理結果の表示
│   ├── moves.js          # アイテムの移し先の判断
│   ├── sorter.js         # アイテムの移動
│   ├── store.js          # チェストへの収納
│   ├── discard.js        # 廃棄と記録
│   ├── cactus.js         # サボテンへの投てき
│   ├── builder.js        # チェストの作成、設置、拡張
│   ├── crafting.js       # 板材、作業台、チェストのクラフト
│   ├── sites.js          # 置く場所の選び方
│   ├── forester.js       # 伐採と植え直し
│   ├── trees.js          # 自然の木の判定
│   ├── window.js         # チェストや作業台の画面の操作
│   └── state.js          # 登録情報の保存
├── scripts/
│   └── check-syntax.js   # 構文検査（CI の build で実行）
├── docs/
│   └── spec.md           # 仕様書
└── .env.example          # 接続設定の雛形
```
